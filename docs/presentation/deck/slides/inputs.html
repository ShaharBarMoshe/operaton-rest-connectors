No token input: the connector sends the accessToken execution variable. Schemas are pasted as JSON or YAML, without comments, and must not contain ${…}; use x-expression instead.

Every REST task in the models carries all inputs, empty when unused, so any modeler shows the full list. The schema rules: paste the schema itself, JSON or YAML, no comment lines, and no dollar-brace expressions inside the schema text because the engine would evaluate them first.
