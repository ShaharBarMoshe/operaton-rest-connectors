TEST MODE · MOCK DATA

Run the process without calling the service

InputValue
mockEnabledtrue, false or an expression
mockStatusthe status to answer with, default 200
mockResponsethe response body, JSON or text

1 · built and validated

Sources, params and body schemas run as for a real call.

2 · not sent

MOCK GET …/profile - not sent, answering 200

3 · handled like a real answer

Status → BPMN errors, response schema, result variables.

mockStatus = 404 tests the “not found” path; a mock body that breaks the response schema ends in RESPONSE_INVALID, like a real one would.

Test mode is set per task in the model, so a test environment can run whole processes with no service available. Because only the call is replaced, everything else, including schema mistakes in the model, is still checked.
