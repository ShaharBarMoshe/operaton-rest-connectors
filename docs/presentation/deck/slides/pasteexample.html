    customerId:
     type: integer

     first: {type: string, x-source: /customer/firstName}

     x-expression: execution.getVariable('initiator')

$ref line

Names the schema to send among the pasted components.

x-source · x-expression

Only where our data is named differently from the service’s.

readOnly id

Not sent in the POST; required in the response, which pastes the same schema unchanged.

Shortened from customer-snapshot.bpmn. The service's document is mock/openapi/customer-api.yaml, served by the mock as GET /openapi.yaml. Orange marks the only lines added to the copy. The response schema field holds the same paste without the additions, so a response without an id like s-1 ends in RESPONSE_INVALID.
