How the variables look at runtime

4 start variables (String, Integer) + 5 GET results of type Json: the value is visible right in the table.

Opening contact: the full GET response, exactly as received (_links included).

The GET results are stored exactly as received, noise included; shaping happens only when a schema builds a request. After the POST, snapshot and postStatus are added, and when the instance completes all of these runtime variables are deleted and none is in history (history level activity).
